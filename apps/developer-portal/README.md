# StarVault Developer Portal

Developer-facing portal for API docs, SDK downloads, authentication, tutorials, examples, Swagger/OpenAPI, and protocol explorer.

This app will eventually live at `developers.starvault.org`.

## v2 Portal Pages

- Quick Start
- Authentication
- SDKs
- Examples
- API Explorer
- Tutorials
- Swagger / OpenAPI
- Protocol Docs
- Application Registry

Goal: first successful API call in under five minutes.
