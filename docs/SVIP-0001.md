# SVIP-0001: Core Consent Request Format

Status: Draft

## Summary

Define the first standard consent request format for the StarVault Protocol.

## Motivation

StarVault exists to turn invisible data extraction into explicit, inspectable, revocable consent. To make that work across apps, AI systems, employers, hospitals, banks, and personal vault nodes, every data request must disclose the same minimum facts.

## Required Fields

- Requester application ID
- Requester display name
- Resource type
- Purpose
- Scope
- Duration
- Export permission
- User benefit
- Retention policy
- Revocation endpoint

## Example

```json
{
  "requester_app_id": "app_model_forge",
  "requester_name": "ModelForge Labs",
  "resource_type": "ai_memory",
  "purpose": "model training dataset licensing",
  "scope": ["read"],
  "duration_seconds": 43200,
  "export_allowed": false,
  "user_benefit": "paid licensing offer",
  "retention": "delete after 12 hours",
  "revocation_endpoint": "https://api.modelforge.example/revoke"
}
```

## Security Notes

Consent must be denied by default. A missing purpose, scope, duration, revocation endpoint, or user benefit should make the request invalid.
