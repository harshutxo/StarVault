# StarVault Research Agenda

StarVault's long-term strength depends on research that lets users control data without forcing applications to collect and store more of it.

## Privacy-Preserving AI

Questions:

- Can AI agents operate on temporary context without retaining it?
- Can model providers prove that data was not used for training?
- Can users set memory permissions that agents reliably follow?

## Confidential Computing

Questions:

- Can sensitive computation happen inside trusted execution environments?
- Can applications receive outputs without seeing raw user data?
- Can vault nodes attest execution environments?

## Verifiable Credentials

Questions:

- Can users prove facts without exposing full documents?
- Can education, employment, medical, and government credentials be verified through StarVault?
- How should credential revocation be represented?

## Zero-Knowledge Proofs

Questions:

- Can users prove eligibility without revealing underlying data?
- Can a user prove age, income range, certification, or residency without disclosure?
- Which proof systems are practical enough for consumer and enterprise use?

## Secure Multi-Party Computation

Questions:

- Can research institutions compute aggregate insights without seeing raw records?
- Can multiple vault nodes contribute to a study without exposing individual data?

## Personal AI Governance

Questions:

- What does consent mean when AI agents act on behalf of a user?
- How should AI memory be scoped, expired, and revoked?
- How should AI agent identities and capabilities be audited?

## Policy-Carrying Data

Questions:

- Can data carry machine-readable usage restrictions?
- Can receiving systems enforce or attest policy compliance?
- How should violations be detected and handled?
