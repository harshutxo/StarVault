# StarVault Design System

StarVault should feel timeless, quiet, precise, and infrastructural. The site is the digital home of a movement, not another SaaS landing page.

## Visual Principles

- Trust, light, intelligence, space, architecture, silence, precision.
- Motion must teach the protocol.
- Every glow should feel earned.
- Avoid cyberpunk, web3 cliches, and neon overload.
- The first impression should feel like the introduction to a new chapter of the internet.

## Palette

| Role | Color |
| --- | --- |
| Primary | Midnight `#020617` |
| Secondary | Deep Space `#08111F` |
| Accent | Electric Blue `#3B82F6` |
| Secondary Accent | Cyan `#22D3EE` |
| Highlight | White `#FFFFFF` |

## Typography

- Headings: Geist
- Body: Inter
- Hero headings: 64-96px, very bold, minimal wording

## Motion

- Subtle packet drift for encrypted streams.
- Node pulses for people, apps, vaults, permissions.
- Line drawing for consent relationships.
- No decorative animation without explanatory purpose.

## Signature Experiences

1. Live Protocol Simulator
2. Interactive Architecture
3. Internet Timeline
4. AI Assistant
5. Live World Map
6. Protocol Explorer
